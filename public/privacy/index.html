Polisi Privasi / Privacy Policy

Kemaskini terakhir: 13 Oktober 2026

Polisi ini menerangkan bagaimana Buat Orang Lapo ("kami") dan aplikasi dalaman kami "BOL Uploader" mengendalikan data.

1. Tujuan aplikasi

BOL Uploader ialah alat dalaman untuk memuat naik, menjadualkan dan mengurus kandungan video di akaun media sosial milik kami sendiri (Facebook Page Buat Orang Lapo, Instagram @buatoranglapo dan saluran YouTube kami), serta membaca dan membalas komen di kandungan tersebut. Ia tidak digunakan oleh orang awam.

2. Data yang kami akses

  • Token akses akaun kami sendiri, disimpan secara selamat dan tidak dikongsi.
  • Kandungan yang kami terbitkan (video, kapsyen, pautan).
  • Komen awam di kandungan kami, hanya untuk dibaca dan dibalas.

3. Penggunaan data

Data hanya digunakan untuk mengurus kandungan dan membalas komen di akaun kami. Kami tidak menjual, menyewa atau berkongsi data dengan pihak ketiga, dan tidak menggunakannya untuk iklan.

4. Penyimpanan

Data disimpan hanya selagi perlu untuk tujuan di atas. Kami tidak menyimpan data peribadi pengguna lain di luar platform asal.

5. Perkhidmatan pihak ketiga

Aplikasi ini menggunakan Meta Graph API dan YouTube API Services. Dengan berinteraksi dengan kandungan kami di YouTube, anda juga tertakluk kepada Terma Perkhidmatan YouTube dan Polisi Privasi Google. Akses boleh dibatalkan di tetapan keselamatan Google.

6. Pemadaman data

Untuk meminta pemadaman data berkaitan anda, hubungi kami di emel di bawah. Kami akan memprosesnya dalam masa 30 hari.
